# Win-2-Linux v1.1.0 — Ubuntu and Zorin fully working

Ubuntu 26.04.1 LTS and Zorin OS 18.1 Core autoinstall are fully working, with successful end-to-end installations confirmed. Select either distribution to configure and stage an automated dual-boot installation from Windows.

## Changes

- Fixed the setup/staging layout shifting sideways after continuing. Content stretches to the window width and resets its scroll position after switching views.
- Removed the fixed content width cap. Distribution cards, hardware status badges, and configuration fields reflow when the window is resized or maximized.
- Added autoinstall completion labels: Ubuntu **100%**, Zorin **100%**, Fedora **~60%**, and Linux Mint **~50%**. These reflect implementation and verification status, not live installation progress or success rates.
- Ubuntu and Zorin display no autoinstall readiness warning on selection. Fedora displays a partial-support warning. Linux Mint displays an unverified-support warning: it uses the same Ubiquity/preseed configuration approach as Zorin and should work, but has not been verified end to end.
- Removed the unused Rust prototype. Both the Windows UI and CLI use the C# core directly; no Rust runtime or Cargo build step is required.
- Includes Zorin's automated preseed preparation, installer-session Wi-Fi recovery, signed Ubuntu 7.3 kernel option, and installation-volume ISO caching from the recent development updates.

## Downloads

- **Win2Linux-v1.1.0-Setup.exe** — self-contained Windows x64 installer, recommended for most users.
- **Win2Linux-v1.1.0-win-x64.zip** — portable, self-contained Windows x64 desktop application. Extract the whole archive and launch `Win2Linux.UI.exe`.
- **win2linux-cli-v1.1.0-x64.exe** — self-contained single-file Windows x64 CLI.
- **SHA256SUMS.txt** — SHA-256 checksums for the three downloads.

## Support status

Fedora autoinstall remains partial and may require manual steps after reboot. Linux Mint autoinstall remains unverified. Secure Boot and system-disk protection remain part of the installation flow, and all distributions still require confirmation before disk allocation.

Back up your data before any installation: this application changes partitions on the selected secondary disk. The signed Ubuntu 7.3 kernel option requires internet access during installation.

## Validation

- Release builds of the Windows UI and CLI.
- All 82 automated tests passed.
- XAML and event handlers compiled successfully. Interactive desktop verification was stopped before the resizing and selection checks completed; these still need a manual check before publication.

No new Linux installation was performed while building this release; Ubuntu and Zorin's end-to-end verification comes from the confirmed installation runs.
